# AutoStock Intelligence — Machine Learning

## Objetivo

Preparar a estrutura para desenvolvimento de modelos
de previsão de demanda e apoio à reposição de estoque.

## Organização

- data/: conjuntos de dados locais.
- preprocessing/: limpeza e transformação.
- training/: treinamento e avaliação.
- inference/: execução de previsões.

## Integração

O módulo ML será desenvolvido separadamente das
operações transacionais do backend FastAPI.

A integração com a API ocorrerá após validação
do modelo preditivo.
