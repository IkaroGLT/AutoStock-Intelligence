# AutoStock Intelligence

Sistema acadêmico de gerenciamento e automação de estoque com API FastAPI, frontend React e módulo de previsão de demanda.

**Status atual:** planejamento da arquitetura e estrutura inicial; o funcionamento completo ainda não foi implementado.
